# 提交材料 · 混凝土框架多工况智能仿真 Agent

> 江苏省高校 AI+ 黑客松 · 赛道 B3 · 参赛编号 **U018** · 模型后端 `agnes-3.0-flash` + PyNite 真实 FEA

---

## 一句话简介

用 **Agnes 大模型 + 真实结构有限元（FEA）**，让 Agent 自己决定"该算哪些工况"，以 **远少于穷举的 FEA 次数**找出混凝土框架中不满足规范的全部危险工况。

---

## 痛点与方案

- **痛点**：混凝土框架设计要对成百上千的参数组合做结构仿真，全空间穷举成本极高（本题 432 组合），而随机盲扫又抓不全危险工况。
- **方案**：把 Agnes 定义为"结构工程仿真助手"，通过 function calling 调度本地 FEA 工具；Agent 自主执行"标定轻/重 → 定位危险区 → 批量加密 → 验证"，并用参数化预算（轮次/FEA 数/墙钟）+ 四种硬终止保证"算得完、停得下"。再加一个高斯过程（GP）代理模型做主动学习，作为采样建议器进一步压低 FEA 次数。

---

## 核心结果亮点（有数字、可复现）

| 方法 | 预算 | 发现危险 | 对比 |
|------|------|----------|------|
| **穷举基线** | 432 次 FEA | 168 / 168（100%） | 参照 |
| **Agnes 智能采样** | 25 次 FEA | 19（76%） | 相对随机 z=**4.69**，效率 **17.3×** |
| **GP 主动学习** | 15 次 FEA | 168（100%） | 随机同期仅 3% |

- 智能采样用 25 次 FEA 达到穷举 432 次才能定位的危险区覆盖率（76%），且危险区分布与穷举**高度一致**（主危险维度 L 向/高层/大活载全中）。
- GP 主动学习更狠：**15 次 FEA 即 100% 覆盖全部危险工况**，离线、可复现、不依赖模型调用。
- 两种独立方法互证，结论稳健。

## 创新点 / 加分项

1. **真实仿真内核**：PyNite 三维框架 FEA，非玩具 mock；规范判据从"绝对利用率"改进为"需求/允许配筋率"，安全/危险可明确区分。
2. **可停下的 Agent**：参数化硬预算 + 四种硬终止 + 会话级摘要，解决 LLM 多轮采样"停不下来/超预算"的工程难题。
3. **GP 主动学习加分**：代理模型做采样建议器，15 次 FEA 即 100% 覆盖危险工况，可叠加主流程进一步增效。
4. **全程可追溯 + 一键导出**：所有 FEA 调用落 JSONL；对比实验复用缓存、零新增 API 调用；交付包含源码/报告/数据集/提示词/终稿的完整归档。
