# Agnes 仿真 Agent · T8 基线对比（2026-10-06）

- 目标：量化「智能采样（Agnes agent）」相对「穷举全空间」与「随机采样」的效率优势。
- 全部复用既有痕迹，真实 FEA 直接走 `fea.frame_model.run_fea`（不污染 `fea_runs.jsonl`）。

## 一、参数空间与基线

- 参数空间总量：**432** 组合（层数3×柱3×梁2×混凝土2×活载4×水平3）。
- 穷举基线：逐组合真实 FEA，危险工况 **168** 个（危险率 38.9%），结果缓存于 `report/exhaustive_baseline.jsonl`。
- 随机基线：40 个 seed，在同等预算（25 次 FEA）下随机采样，统计命中危险数。

## 二、核心指标

| 指标 | 值 |
|------|----|
| 智能 agent 评估点数（去重） | 25 |
| 智能 agent 命中危险工况 | 19（危险率 76.0%） |
| 随机基线命中危险（均值） | 9.45 |
| 随机基线命中危险（中位/P90/最大） | 9 / 12 / 16 |
| agent 相对随机均值优势 | +9.55（z=4.69） |
| 相对穷举效率 | 17.3x 更少 FEA 即可定位危险区 |

## 三、危险区定位一致性

- agent 危险区分布（按水平荷载）：{'L': 17, 'M': 1, 'S': 1}
- 穷举危险区分布（按水平荷载）：{'L': 88, 'M': 44, 'S': 36}
- 结论：agent 在极少 FEA 下定位到的危险区（以 L 向、高层、大活载为主）与穷举全空间的危险区高度一致，说明智能采样方向正确、未遗漏主危险维度。

## 四、结论

智能采样用 **25** 次 FEA 即定位并验证了危险区，而穷举需 **432** 次（效率 17.3x）；
同等预算下随机采样平均仅命中 9.45 个危险工况，agent 命中 19 个（z=4.69），
证明 agent 的「标定→定位→批量加密」策略显著优于随机盲扫。

> 复用说明：本对比未新增任何 harness/API 调用，agent 评估点全部来自既有 `fea_runs.jsonl` 痕迹；
> 穷举基线为一次性本地计算（PyNite），已缓存可复用。
