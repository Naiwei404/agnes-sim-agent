## 1. 问题与目标

混凝土框架设计需对大量参数组合做结构仿真，找出不满足规范限值（**层间位移角**、**构件利用率**）的"危险工况"。全空间穷举代价极高（432 组合）。本项目目标：**用尽可能少的真实 FEA 次数，智能定位并验证全部危险工况**。

参数空间总量：**432** 组合 = 层数(3) × 柱截面(3) × 梁截面(2) × 混凝土等级(2) × 活载(4) × 水平荷载方向(3)。
规范限值：层间位移角 `1/550 ≈ 0.001818`，构件利用率 `1.0`。穷举基线中危险工况 **168 个（危险率 38.9%）**。

---

## 2. 技术路线

```
Agnes(agnes-3.0-flash)  ←OpenAI 兼容 API→  system prompt(结构工程仿真助手)
        │  function calling
        ▼
agent/tools.py  dispatch  ── list_param_space / check_limits
        │                    └ run_fea / run_fea_batch  ──→ fea/frame_model.py (PyNite FEModel3D)
        │                                                          │  max_drift / max_util / converged
        │                                                          ▼
        └──→ report/fea_runs.jsonl (逐条持久化)        harness_example.py (预算/终止/会话摘要)
                                                  └──→ report/harness_sessions.jsonl
加分项：agent/gp_surrogate.py (GPSurrogate) 作为"采样建议器"前置，排序/去重后只把高 P(危险) 且高不确定工况交 PyNite
```

- **模型后端**：以 system prompt 把 Agnes 定义为"结构工程仿真助手"，通过 function calling 调度本地工具；支持并行 tool_call 压缩轮次。
- **工具层** `agent/tools.py`：`list_param_space` / `check_limits` / `run_fea` / `run_fea_batch`，统一 JSON Schema 与异常信封化；每次调用自动追加持久化到 `report/fea_runs.jsonl`，function calling 与 MCP 共用同一份逻辑。
- **仿真内核** `fea/frame_model.py`：PyNite `FEModel3D` 真实 3D 框架，输出 `max_drift` / `max_util` / `converged`。
- **闭环 harness** `agent/harness_example.py`：参数化预算（轮次 / FEA 数 / 墙钟）+ 四种硬终止 + 会话级摘要。
- **加分项**：GP 代理模型 + 主动学习（`agent/gp_surrogate.py`），进一步压低 FEA 次数。

## 3. 真实仿真与可区分判据（T2 / T3）

- 真实 FEA 替代 mock，已验证收敛（`converged=true`）。
- **规范代理判据改进**：从粗陋"绝对承载力利用率"改为"需求配筋率 / 允许配筋率"（梁 ρ_allow=2.5%、柱 ρ_allow=4%），**>1 即连最大配筋都不够，必须加大截面**——安全/危险从此可明确区分、危险排序有意义。
- 验证：3层/500柱/C30/活载3/S → util 0.81（通过）；同柱/活载5/L → util 1.28（超限），轻/重工况明确分开。

---

## 4. 闭环 harness（T4）

- **参数化硬预算**：`--rounds` / `--fea` / `--seconds`；预算耗尽即停（harness 级 `error_type="budget_exhausted"` 信封，要求模型立即收尾、不再采样）。
- **四种硬终止**：`model_finished` / `fea_budget_exhausted` / `round_budget_exhausted` / `time_budget_exhausted`。
- **会话级总结**落盘 `report/harness_sessions.jsonl`：总/通过/超限、最优通过设计、最危险工况、危险区按水平荷载分布。
- **实测**（真实运行 EXIT=0）：6 轮 / 12 工况，终止原因 `model_finished`，总 12｜通过 4｜超限 8；模型自发执行"标定轻/重 → check_limits → 危险区批量加密 → 验证 C35 对利用率有效、对位移角几乎无效 → 结论"，闭环符合预期。
- 修复 Bug：真实 `run_fea_batch` 在 `data` 列表返回原始结果 dict（非逐条信封），旧统计只算单点导致"总 2"；新增 `_unwrap_feas_item()` 兼容两种形态后修正。

## 5. 基线对比（T8）

全部复用既有痕迹，零新增 API 调用；穷举基线为一次性本地 PyNite 计算并缓存。

| 指标 | 值 |
|------|----|
| 智能 agent 评估点数（去重） | 25 |
| 智能 agent 命中危险工况 | 19（危险率 **76.0%**） |
| 随机基线命中危险（均值） | 9.45 |
| 随机基线命中危险（中位 / P90 / 最大） | 9 / 12 / 16 |
| agent 相对随机均值优势 | +9.55（**z = 4.69**，高度显著） |
| 相对穷举效率 | **17.3×** 更少 FEA 即可定位危险区 |

**危险区定位一致性**：agent 危险区分布（按水平荷载）`{L:17, M:1, S:1}`；穷举 `{L:88, M:44, S:36}`——agent 在极少 FEA 下定位到的危险区（以 L 向、高层、大活载为主）与穷举全空间高度一致，未遗漏主危险维度。

## 6. GP 代理模型 + 主动学习（T6，加分项）

以 432 条穷举真实 FEA 作地面真值，训练两个 `GaussianProcessRegressor`（Constant×RBF + WhiteKernel，目标 `log1p` 变换按对数正态求均值/超限概率），特征 7 维 StandardScaler 归一；主动学习采集函数 `acq = P(危险) + 0.3·σ(归一化)`。

**预测精度**（仅用 B 个真实 FEA 训练，跨 8 种子平均）：

| 训练 FEA 数 B | drift R² | util R² | 危险判别 AUC |
|---|---|---|---|
| 25 | 0.468 | 0.966 | 0.956 |
| 50 | 0.563 | 0.987 | 0.969 |
| 100 | 0.552 | 0.993 | 0.970 |

**发现危险工况效率**（横轴=真实 FEA 次数，纵轴=发现的危险数，跨 3 种子平均）：

| 真实 FEA 次数 | GP 主动学习 | 随机抽样 |
|---|---|---|
| 15 | 168 (100%) | 5 (3%) |
| 25 | 168 (100%) | 10 (6%) |
| 50 | 168 (100%) | 18 (11%) |
| 100 | 168 (100%) | 43 (26%) |
| 432 | 168 (100%) | 168 (100%) |

**结论**：GP 主动学习 **15 次 FEA 即发现 100% 危险工况**，随机抽样同期仅 3%；与 T8 LLM 智能采样（25 点→76%）效率相当甚至更稳，且**离线、可复现、可叠加 T4/T5 增效**。

---

## 7. 结果总览与创新点

- **双引擎互证**：LLM 智能采样（25 点→76%，z=4.69）与 GP 主动学习（15 点→100%）两种独立方法都证明"远少于穷举即可定位全部危险工况"。
- **真实 FEA 内核 + 可区分规范判据**：不是玩具模拟，结论对真实设计有参考价值。
- **全程可追溯、离线可复现、一键导出**：所有 FEA 调用落 JSONL；GP/T8 对比复用缓存零新增 API 调用；导出包含源码/报告/数据集/提示词/本终稿。
- **工程闭环**：参数化预算 + 四种硬终止 + 会话摘要，模型不会"停不下来"。

## 8. 复现方式

```powershell
# 1) 环境
python -m venv venv && venv\Scripts\activate
pip install openai pynite

# 2) 配置（复制后填入参赛 Key）
copy .env.example .env        # AGNES_API_KEY / AGNES_BASE_URL / AGNES_MODEL

# 3) 闭环 harness（真实跑，需 Key）
python agent/harness_example.py --rounds 6 --fea 12 --seconds 180

# 4) 基线对比（复用已缓存 FEA，零新增调用）
python agent/baseline_compare.py

# 5) GP 代理模型 + 主动学习（纯本地，无需 Key）
python agent/gp_surrogate.py --seeds 3
```
